## 2. 修复明细

### R1 最终回合的胜利类型

规则 25.3 的 Victory Determination 顺序是：先检查标准胜利（≥25 VP），再检查支配胜利，最后才是“仍未决出胜者且不是第 7 回合则进入下一回合”。原实现把 `G.year > G.endTurn` 放在最前，导致第 7 回合冬季加分后达到 25 VP 的对局被判成时限胜利。

修复后的顺序：

```text
未到胜利结算阶段 → 无胜利（时限兜底保留）
VP ≥ 25            → standard（平局按 25.3 裁定）
第 4 回合起、领先 ≥5 → domination
超过最后一回合      → timeLimit
```

`src/virginQueen/virginQueen.test.ts` 的“时限胜利”用例原本未平衡比分，实际上先满足支配胜利；已改为先拉平各势力 VP 再断言时限胜利，并新增“最终回合达到 25 VP 判标准胜利”。

### R2 记录不完整时不得当作 0

`vpTieBreak`（原 `breakVpTie` 的完整实现）现在只使用**所有仍并列势力都有记录**的回合：

```text
hist === undefined || !remaining.every((p) => hist[p] !== undefined) → 跳过该回合
```

这样旧存档、中途加入或未填写的记录不会把某个势力当成 0 分淘汰。

### R3 无历史记录时的确定性回退

规则未规定“追溯到首回合仍并列”的处理方式；勘误把 24.6 外交平局改为“行动顺序最靠前者获胜”。程序采用同一约定：按行动顺序（奥斯曼 → 西班牙 → 英格兰 → 法国 → 神圣罗马 → 新教）取第一者，并在结束面板明确写出“按行动顺序”。

`vpTieBreak` 返回完整轨迹（`tied` / `steps` / `winner` / `decidedBy`），供界面解释；`breakVpTie` 保留为只取胜者的薄封装，避免现有调用点改动。

### R4 结束面板平局说明

新增 `vpTieBreakSummary(G, locale)` 与 `describeVpTieBreak(trace, locale)`：

- 仅对 `standard` / `timeLimit` 显示（即时胜利按当时的 VP 直接比较，不走历史记录）；
- 有决定性回合时显示：`西班牙、法国 并列为最高 VP，按上一回合结束时的 VP 记录裁决：第 5 回合的 VP 为 西班牙 22、法国 16，由 西班牙 获胜。`
- 无历史记录时显示：`… 此前各回合仍无法分出胜负，按行动顺序由 西班牙 获胜。`
- 无并列时不显示任何额外文本；
- 教学剧本不显示（该剧本的时限胜利由特殊规则判给西班牙）。

### R5 VP 记录表布局

原来的表以势力为行、回合为列，表头是 `第N回合`：

- 6 个回合时表格 408px，侧栏内容区 334px，最后一列被裁切；
- `vq-intel .vq-disclosure-content` 自带 `overflow: auto`，但没有提示可以横向滚动。

改为更紧凑的形态：

- 表头列名改为“回合 / Turn”，每个回合只显示数字（完整标签放在列与单元格的 `title` 中）；
- 单元格内边距从 6px 收到 2px，色块 8px → 7px，表格宽度 100%；
- 新增 `.vq-vp-history` 样式：细分隔线、领先格底色高亮、末行去掉多余边线；
- 说明文字从 `title` 提升为表格下方的常驻说明，热座玩家不必悬停才能看到规则。

实测 1440 / 1280 / 390 三种宽度下表格均完整落在侧栏内（1440 下 334px = 内容区宽度；390 手机“局势”标签页 348px，页面无横向滚动）。

### R6 结束面板的回合与阶段

冬季结算在判定胜负前已把 `G.year` 加一，因此：

- 标准 / 支配 / 时限胜利：显示 `G.year - 1`（刚完成的回合），并仍以 `endTurn` 封顶；
- 即时胜利（军事 / 宗教 / 天主教叛乱）：发生在当前行动阶段，显示当前回合；
- 对局结束后不再显示阶段名（`Card Draw 阶段` 等已无意义）。

新增回归：冬季判定的标准胜利显示“回合 5”而不是“回合 6”；行动阶段的即时胜利仍显示“回合 3”；结束后页面不含 `Card Draw 阶段`。

### R7 规则可见性

“场景与胜利条件”的 `vpVictoryGoalHint` 补充平局裁定与行动顺序回退；`VIRGIN_QUEEN.md` 的胜利章节重写为：

- 时限胜利补充“若第 7 回合结束时恰好达到 25 VP，仍按标准胜利结算”；
- 新增“平局裁定（25.3）”条目，说明逐回合回溯、VP 记录位置、未公开神圣罗马宗教 VP 不计入、行动顺序回退。

## 3. 对局路径与复现

1. 打开 `/localVQ`，选择 Campaign · 拉罗谢尔之围 · 6 人。
2. 通过六个席位的热座客户端推进到第 6 回合（本轮使用浏览器内注入状态复现，避免强制事件驱动的失败）。
3. 设定西班牙与法国均为 27 VP、英格兰 24 VP，写入 1–6 回合的 VP 记录（第 5 回合西班牙 22 / 法国 16）。
4. `checkVictory` 返回 `{winner: "spain", reason: "standard"}`；结束面板：

5. 清空 `vpHistory` 后重算：同一比分改为 `… 此前各回合仍无法分出胜负，按行动顺序由 西班牙 获胜。`
6. 展开“VP 记录”：6 个回合全部可见，领先格高亮，1440 / 1280 / 390 三种宽度均无横向溢出。
7. 用真实的 4 次 `winter()` 记录验证：第 3 回合西班牙 17 / 法国 12 打破平局，面板引用的是“第 3 回合”。

## 4. 规则复核

- **25.3 顺序**：标准 → 支配 → 时限；第 7 回合冬季加分后达到 25 VP 判标准胜利。
- **平局回溯**：只保留仍并列者，逐回合向前，只读取所有并列者都有记录的回合。
- **神秘 VP**：`powerVp` 不含未公开的神圣罗马宗教 VP，`vpHistory` 在冬季公开检查之后写入，因此记录与公开信息一致。
- **即时胜利**：25.1 的“同一行动触发多个自动胜利”按当时 VP 比较，再用 25.3 的历史裁定；结束面板不显示历史说明，避免误导。
- **行动顺序回退**：本条是规则未覆盖情形的确定性约定，界面上明确写出“按行动顺序”，并在 `VIRGIN_QUEEN.md` 中标注为程序约定而非官方规则。

## 7. 后续建议

1. 25.1 同时触发多个自动胜利时，结束面板目前只显示胜者与原因；可补充“另一项条件也成立”的说明，便于复盘。
2. VP 记录目前只有文本表格；可增加“上一回合 / 决定性回合”标注，直接高亮裁定所用的那一列。
3. 热座自动推进脚本仍无法处理强制事件（大维齐尔等），本轮改用浏览器内注入状态复现；若继续做长局自动回归，建议在 `perf/` 之外单独维护一个能结算强制事件的驱动。
4. `e2e/local-smoke.spec.ts` 的电影百年用例与本轮无关但长期失败，建议单独修复或标记跳过，避免掩盖 VQ 的 e2e 结果。
