## 2. 修复明细

### R1 天主教宗教胜利不可达

Scenario Book 的 Protestant Spaces 轨道在 Campaign / Tournament 分别从 **18 / 30** 起算；本仓库的重建地图只绘制了 **9 / 21** 个新教地区。原实现通过

```text
轨道 = 印刷起始值 + (当前地图新教地区数 - 开局地图新教地区数)
```

把两者绑定。由于 `religionCandidates` 遵守“每个斗争区至少保留 1 个新教地区”的核心存在规则，地图最多只能减少 `9 - 4 = 5`（Campaign）或 `21 - 4 = 17`（Tournament），轨道最低分别是 **13 / 13**，达不到 9。

修复：

- 新增 `G.protestantOffMapInitial` 与 `G.protestantOffMapConverted`，把印刷轨道与重建地图的差值（两个剧本都是 9 个）按各区域地图新教地区数比例分配：
  - Campaign：法兰西 4 / 尼德兰 1 / 英格兰 3 / 苏格兰 1
  - Tournament：法兰西 5 / 尼德兰 2 / 英格兰 1 / 苏格兰 1
- 当天主教转化在某区域把地图压到最后一个新教地区、且该区域仍有未绘制地区时，转化改为移除 1 个未绘制地区；日志写“Converted off-map: N Protestant space(s).”
- 新教转化在该区域地图只剩最后一个天主教地区时，可以把未绘制地区恢复为新教；日志写“Restored off-map: N Protestant space(s).”
- `protestantSpaceCount` 改为
  `印刷起始值 + 地图差值 - 已转化的未绘制地区数`，
  因此开局仍是 18 / 30，最小值可到 4，9 的门槛可达。

这样既保留 Scenario Book 的印刷轨道和 VP 表，又不会因为重建地图缺少地区而让天主教胜利永远无法发生。

### R4 胜者判定计入未绘制地区

规则 25.1：法国与苏格兰合计保留 3 个或更少新教地区时法国获胜，否则西班牙获胜。未绘制地区模型加入后，只统计地图会漏掉两地尚未绘制的新教地区。修复为：

```text
法国+苏格兰 = 地图法国新教地区 + 地图苏格兰新教地区
            + 法国未绘制新教地区 + 苏格兰未绘制新教地区
```

新增回归覆盖：轨道同为 9、地图上法国/苏格兰只有 2 个新教地区，但法国仍有 3 个未绘制地区时，胜者必须是西班牙。

## 3. 对局路径

1. 第 1 回合 Card Draw：六国依次确认抽牌。
2. 外交阶段：六国依次结束外交回合（本轮不做宣战/婚姻）。
3. 春季部署：六国依次结束；神圣罗马帝国秘密选择“天主教”并保留一张本国牌。
4. 行动阶段：
   - 西班牙打出牌获得 CP，在英格兰布道（Preach Sermon，5 次天主教转化）。
   - 法国打出牌获得 CP，在法兰西镇压异端（Suppress Heresy，5 次天主教转化）；法兰西接近最后地区后改在苏格兰镇压。
   - 其他势力按顺序出牌并结束行动轮次。
5. 新教地区轨从 18 依次下降；某次转化后跨过 9（本轮最终为 8）。
6. `endIf` 立即返回 `{power: "spain", reason: "catholicReligious"}`，游戏在行动阶段即时结束。
7. 结束面板显示：
   - `对局结束 · 胜者：P2 西班牙`
   - `原因: 天主教宗教胜利：新教地区降至 9 个或以下`
   - `法国在法国与苏格兰合计保留 3 个或更少新教地区时由法国获胜；否则由西班牙获胜。`

## 4. 规则复核

- **即时胜利时机**：`checkImmediateVictory` 在行动阶段每次 move 后的 `endIf` 中检查；本轮在法国镇压后立即结束，未进入冬季，符合规则 25.1。
- **门槛**：`n <= 9` 触发；本轮从 12 一次降到 8，也正确触发，文案已改为“9 个或以下”。
- **胜者归属**：把法国/苏格兰地图新教地区与两地未绘制地区合并后大于 3，因此西班牙获胜；旧实现只看地图会把本轮误判为法国。
- **核心存在**：地图每个斗争区至少保留 1 个新教地区；未绘制地区模型只在该区域地图已到最后一个地区后使用，不绕过该限制。
- **印刷轨道**：开局仍为 18 / 30；西班牙/英格兰/新教/神圣罗马的宗教特殊 VP 仍按官方轨道计算。
- **未绘制地区恢复**：新教在该区域地图只剩最后一个天主教地区时可恢复未绘制地区，避免天主教转化成为不可逆的单向轨道修改。

## 7. 后续建议

1. 未绘制地区是重建地图与印刷地图差异的折中；后续若补齐 Scenario Book 的完整新教地区，可删除 `protestantOffMap*` 并把轨道完全绑定地图。
2. 可在地图上增加“未绘制地区”提示或宗教轨详情，让玩家知道为什么地图没有变化但轨道下降。
3. 热座自动推进工具需要识别强制事件牌：强制事件不能作为 CP 打出，只能作为事件结算；本轮试玩中曾因此卡住奥斯曼/法国的行动轮次，属于规则限制而非引擎错误。
4. 天主教胜利结束面板目前只显示胜者与规则说明；可进一步显示“法国/苏格兰当前新教地区数”，便于复盘。
5. 同一行动同时满足多个即时胜利条件时，规则 25.1 要求按 VP 最高者裁决；当前 `checkImmediateVictory` 仍按“宗教 → 军事”的固定顺序返回第一个条件，建议后续统一比较。
