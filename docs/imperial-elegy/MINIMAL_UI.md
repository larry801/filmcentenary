# Imperial Elegy — One Sheet（极简界面）

**Status:** Implemented, normative for colour, type, surfaces and chrome.
**Revision:** 1.0 — 2026-11-25
**Supersedes:** `VISUAL_SYSTEM.md` (The Imperial Field Atlas), for everything
listed under §1. Behaviour and rules are still specified by
[`README.md`](README.md) and [`UI_CHECKLIST.md`](UI_CHECKLIST.md).

---

## 1. Intent

The board is a **single printed sheet on a plain table**: white paper, black
ink, one blue pencil for the thing to press, one red pencil for a decision that
is owed. Nothing else is drawn.

What changed from the Field Atlas:

| Removed | Replaced by |
| --- | --- |
| Two self-hosted webfonts (EB Garamond + Libre Franklin) | one platform sans, 12–26 px |
| Dark oilcloth shell, noise texture, radial vignette | `#F4F2EC` paper ground |
| Brass fills and keylines | one ink-blue accent `#1F5A78` |
| Panel gradients, inset highlights, drop shadows | 1 px hairlines |
| Seat strip row + track strip row | one 44 px status row |
| 148 px player-mat column | four figures in the status row; the full printed display in the reference drawer |
| 212 px hand tray always open | folded 44 px bar by default; 152 px card strip when opened |
| 348 px permanent turn panel | an orders drawer over the map, closed until asked for |
| Four-button sequence stepper | one step chip that opens the reference |

The rules engine, the printed map, the card faces, both UI languages and every
`data-testid` that names a control are unchanged.

## 2. Colour

Values live in `src/imperialElegy/design/tokens.json`; the stylesheet is
generated by `scripts/generate-ie-tokens.mjs`. No other file may carry a hex.

| Token | Value | Role |
| --- | --- | --- |
| `--ie-table` | `#F4F2EC` | page ground |
| `--ie-panel` | `#FFFFFF` | panel, drawer, card strip |
| `--ie-panel-2` | `#F8F6F1` | raised plate |
| `--ie-panel-3` | `#F0EDE6` | hover plate |
| `--ie-rule` | `#E3DFD4` | decorative hairline |
| `--ie-rule-strong` | `#8F8A7C` | control boundary (3.08:1 on the ground) |
| `--ie-on-dark` | `#1A1B1D` | primary text |
| `--ie-on-dark-2` | `#4C4E53` | secondary text |
| `--ie-on-dark-muted` | `#64676C` | meta text (4.86:1 on the hover plate) |
| `--ie-brass` | `#1F5A78` | the one accent: primary action, focus, selection |
| `--ie-overprint` | `#A3372A` | decision owed, hostile |
| `--ie-move-ink` | `#2F5D7C` | legal-move ring on the atlas |
| `--ie-paper` | `#F2E9D8` | the atlas sheet and the card faces (artwork) |

`--ie-*` names keep their historical spelling (`on-dark`, `brass`) because 669
`ie-*` classes and the MUI theme read them; the values above are what they
mean now. The nine power fills are data and are byte-identical to
`POWER_DEFS`.

**Rules**

1. The accent marks exactly one primary action per surface, plus focus and the
   current selection. It is never used for decoration.
2. Red means "a decision is owed" or "hostile". It is never emphasis.
3. Power colour appears only inside counters, pips, chips and card faces.
4. Text is `--ie-on-dark*` on chrome and `--ie-ink*` on paper. A power fill
   never carries small text.
5. Every text pair ≥ 4.5:1, every boundary and focus ring ≥ 3:1. `yarn
   ie:contrast` computes all 87 pairs from the token file and fails the build.

## 3. Typography

One family: `system-ui, -apple-system, "Segoe UI", "PingFang SC", "Hiragino
Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`. No webfont is
downloaded, so Latin and CJK share one optical size and one loading state.

| Step | Size | Line (en / zh) | Weight | Use |
| --- | --- | --- | --- | --- |
| xs | 12 px | 16 / 18 | 500 | labels, meta, chips |
| sm | 13 px | 18 / 20 | 400 | body, log |
| md | 14 px | 20 / 22 | 400 | panel body |
| lg | 18 px | 24 / 26 | 600 | panel and section titles |
| xl | 22 px | 28 / 30 | 600 | dialog titles |
| 2xl | 26 px | 32 / 36 | 600 | the setup screen's h1 |

12 px is the floor (`ieTokens.test.ts` enforces it; only `.ie-rule-ref` may go
to 10 px). Numerals are tabular everywhere. Letter-spacing is 0 in both
languages except 0.02 em on uppercase micro-labels.

## 4. Surface and motion

- One hairline (`1px var(--ie-rule)`) separates regions; panels keep a 1 px
  border and no shadow.
- The only shadows are `--ie-shadow-2` (popover, 0 8px 24px at 10 %) and
  `--ie-shadow-3` (drawer, dialog, mobile dock).
- Radii: 2 px for controls, 3 px for surfaces. No pills outside pips.
- Focus: `2px solid var(--ie-focus-dark)` with a 2 px offset, on every
  focusable control.
- Motion: 100 ms press, 160 ms popover, 180 ms sheet; opacity and translate
  only; `prefers-reduced-motion` disables all of it.
- No gradient, texture, blur, bevel or ornament pseudo-element carries
  information or adds layout height.

## 5. Structure

Layout at 1440×900:

```
┌──────────────────────────────────────────────────────────────┐
│ 44 px  status row: turn · step · seats · VP/stab/MP/ind · WTT │
│        alliance pips · CP · Orders · ? · menu                 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  map (full width, ~1390 × 730)      ┌ orders drawer 348 px ┐ │
│                                     │ only while open      │ │
├─────────────────────────────────────┴──────────────────────┤ │
│ 44 px  hand bar (folded)  /  152 px card strip when opened   │ │
└──────────────────────────────────────────────────────────────┘
```

- **Status row** — `components/TrackStrip.tsx` (class `ie-track-strip`). The
  hotseat's seat tabs render inside it through `SeatUiContext.seats`; the
  shell's own controls (new game, help, difficulty) live in its menu
  (`SeatUiContext.shellMenu`). One row, one turn readout.
- **Figures** — VP, stability, manpower and industry, from `core.me`. The
  printed display (all tracks and boxes) is the reference drawer's first
  section (`ie-ref-mat`), rendered from the same `PlayerMat` the phone's dock
  tab shows.
- **Orders drawer** — `TurnPanel` inside `.ie-turn-slot`. Closed by default,
  opened by the status row's `指令 / Orders` button, by a pending decision or a
  battle, and closed by `Esc` or its ×. It is `inert` while closed. The War and
  Log tabs stay inside it.
- **Hand** — `HandTray` folded to a 44 px bar by default. Opened, a card row is
  CP · name · its two printed plays (CP and event); industrialise, show, the CP
  chain and Save live in the card inspector the name opens. The CP-chain strip
  stays in the row.
- **Phone** — unchanged in shape: one bottom dock whose tabs are Orders, Hand,
  Mat, Log and War. `.ie-turn-slot` is `display: contents` there, so the dock
  still owns the height.
- **Reference drawer** — right-hand drawer (`60-overlays.css`), opened by `?`,
  a step chip or a rule link; it now also carries the player's own display.

## 6. Interaction

- A move is one gesture: select the unit or space, click the highlighted
  target. Irreversible decisions (declare war, play an event, pass) keep the
  arm-then-confirm control, and the Display menu can turn confirmations off.
- Every surface shows at most one accent-filled button: the next thing to do.
- `Enter` confirms, `Esc` closes the topmost surface, `1`–`6` switch hotseat
  seats, `?` opens the reference.
- Nothing is reachable only by hover; every control has a visible label or an
  `aria-label`.

## 7. Verification

Local, before a push:

```sh
yarn tsc --noEmit          # types
yarn test                  # unit + component suites
yarn ie:tokens:check       # generated tokens match tokens.json
yarn ie:contrast           # 87 contrast pairs
yarn build                 # production bundle
```

A throwaway Playwright audit lives outside the repository (no browser suite is
committed): it walks every visible text node, computes the colour against its
effective background, and reports any pair below 3.6:1, any
`background-image` or `box-shadow` on a non-overlay surface, and the region
boxes. The 2026-11-25 run reports 0 low-contrast nodes, 0 gradients and 0
panel shadows at 1440×900 and 390×844.

GitHub Actions (`ci.yml`) remains the authoritative gate: types, the Jest
suites, the token and contrast scripts, the production build, the single-file
bundle boot, and the three seeded self-play jobs. The Imperial Elegy Playwright
specs were deleted with this redesign — they pinned the old shell's regions and
ports — so there is no browser regression gate for this game; screenshots under
`docs/qa/ie-minimal-2026-11-25/` are the visual record.

## 8. Non-goals and known deviations

- No rules, engine, data or copy change; no change to any `data-testid` that
  names a control.
- The map, card faces and ASCII-free printed sheets stay as published art.
- Other games (宋金战争, 电影百年, Virgin Queen) are untouched.
- **Deviation 1 —** the phone dock keeps five tabs (Orders, Hand, Mat, Log,
  War) instead of three: the War tab is the only home of a declaration, and
  the mat tab is the phone's only full player display.
- **Deviation 2 —** the hand's secondary card operations moved into the
  inspector rather than into a "…" popover on the row; the inspector was
  already the full-operation surface and one popover less is one component less.
- **Deviation 3 —** the status row keeps the World Tension pips and the five
  alliance boxes. They are live public state that no other always-visible
  surface prints.
