# Asset provenance

All published images come from `Imperial Elegy 1.1.0-beta.4.vmod` (VASSAL
3.7.26, module description “By Mike Lorino @Vuca Games (beta)”). The extraction
script copies the files byte-for-byte; it does not recolour, crop or re-encode
artwork.

The nine reference charts additionally have a **bilingual text transcription**
under `src/imperialElegy/components/referenceCharts/`, rendered by
`components/ChartTextView.tsx`. It is markup, not art: no new image is produced
and the published PNGs stay untouched. Where the printed sheet, the rulebook and
the Mar. 2026 errata disagree, the transcription prints the sheet and adds the
errata note; see `IMPLEMENTATION_STATUS.md`.

The manifest at `public/imperial-elegy/manifest.json` is the authoritative
list. It is plain JSON and does not declare a `$schema` (there is no companion
schema file). For each asset it records:

- `kind` and game id;
- `original` — the archive path (for example `images/Map-World f.jpg`);
- `published` — the path under `public/imperial-elegy/`;
- `checksum` — SHA-256 of the published file;
- `bytes`, `width`, `height`;
- `source` — the module element that referenced it;
- `note` — e.g. the UK display selection.

### Derived table textures

The 3D table (`TABLE_3D.md`) cannot hand a 15.7 MB / 42-megapixel scan to a
phone GPU, so it uses two derivatives of `maps/world.jpg`:

| Published | Size | Bytes |
| --- | --- | --- |
| `maps/world-table.jpg` | 4096 × 2903 | 2.9 MB |
| `maps/world-table-small.jpg` | 1024 × 726 | 0.2 MB |

They are generated by `scripts/generate-ie-table-textures.py`, which records
their SHA-256 in `src/imperialElegy/data/generated/table-textures.json`;
`yarn ie:table:check` verifies them in CI. They are deliberately absent from the
module manifest, which already covers their source scan.

The standees on the same table wear the module's own counters rather than a
lookalike drawn from the palette, so `units/` publishes those faces under a role
name the scene can resolve without guessing from a filename: one front per
power and counter family, the back the module's "Reduced" layer flips to, and
`units/reserve-badge.jpg`. The extraction script copies them byte-for-byte like
every other asset, and `python3 scripts/extract-imperial-elegy.py --check`
covers them.

Run `python3 scripts/extract-imperial-elegy.py --check` to verify every
checksum. The generator omits timestamps, so an unchanged module produces an
unchanged manifest.

## Text cards

Two cards have no face image in the archive: Wilhelm II (#82) and French
National Goal #22. Card 21 also lost its image to a duplicate slot. These are
rendered by the UI as styled text cards. They are recorded in the manifest as
game data (not image assets) and documented in `CORRECTIONS.md`.

## Not published

- Promotional cards P1–P3 (`Action Card P1.jpg` …): deferred promotional
  content.
- Bot reference charts (`Chart Bot 1.png`, `Chart Bot 2.png`): not published as
  art; their B1/B2 tables are transcribed into `src/imperialElegy/engine/bot.ts`.
- `Playerboard UK.jpg`: superseded by the module-selected PNG.
- `Card Deck Map.jpg`, `Map Card Deck.jpg`: deck-layout boards, not game art.
